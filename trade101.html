Section 01

Futures basics: what you're actually trading

Stock index futures

Contracts that track an index (S&P 500, Nasdaq-100, Dow, Russell 2000). You trade the direction of the index with leverage, nearly 23 hours a day, without owning any stocks. Popular tickers: ES, NQ, YM, RTY — and their micro versions MES, MNQ, MYM, M2K.

Micro futures — the beginner's entry point

Micro E-mini contracts (MES, MNQ) are 1/10th the size of standard E-minis. One MES point = $5 instead of $50. Smaller margins, smaller losses while you learn — the standard on-ramp for new futures traders.

Options on futures

Calls and puts on futures contracts let you define risk around events (Fed meetings, CPI releases, earnings weeks). Buying options caps your maximum loss at the premium paid — useful when planning around binary events.

Leverage cuts both ways

Futures margin lets you control a large notional value with little capital. A 1% index move can be a large % move on your account. Risk management is not optional — it is the strategy.

Section 02

NinjaTrader setup, step by step

NinjaTrader 8 is free to download and use in simulation mode. Do everything below in SIM before any live account exists.

  1. 01

    Download & install

    Get the desktop platform from ninjatrader.com (Windows; Mac users typically run it via a VPS or Parallels). Create a free account — this unlocks the simulator and free real-time futures data for sim trading.

  2. 02

    Connect a data feed

    Control Center → Connections. Use the free NinjaTrader/Kinetick sim data to start. Serious latency-sensitive automation later tends to move to Rithmic or CQG feeds for reliability.

  3. 03

    Open a chart & learn the DOM

    New → Chart → instrument MES 09-26 (front month). Add a 5-minute chart plus the SuperDOM for order entry. Practice placing bracket orders (entry + stop + target as one unit) in SIM.

  4. 04

    Set ATM strategies (automatic risk)

    Create an ATM template so every entry automatically attaches a stop-loss and profit target — e.g., 10-tick stop / 15-tick target on MES. This is your seatbelt; never trade without it.

  5. 05

    Build your first automated strategy — no code

    Control Center → New → Strategy Builder. NinjaTrader's Strategy Builder lets you create rule-based strategies with point-and-click logic — entries, exits, stops, targets — and it generates NinjaScript (C#) behind the scenes that you can open and edit later if you outgrow the visual tool.

  6. 06

    Backtest in Strategy Analyzer

    New → Strategy Analyzer. Run your strategy over 1–2 years of historical data with realistic commissions and slippage. Check profit factor, max drawdown, and trade count. Then walk it forward on data the optimizer never saw.

  7. 07

    Run live in SIM for weeks, then go micro

    Enable the strategy on your SIM account from the chart (right-click → Strategies). Only after weeks of stable sim results, fund a live account and start with a single micro contract (MES/MNQ).

Section 03

Automation strategies that traders actually run

TREND

Opening Range Breakout (ORB)

Mark the first 15–30 minutes' high/low; enter on a break with volume confirmation, stop on the other side of the range. One of the most automated setups on index futures.

TREND

EMA crossover trend following

Fast EMA crosses slow EMA (e.g., 50/200 or 9/21 intraday) → enter with trend; exit on reverse cross or trailing stop. The classic first Strategy Builder project.

REVERSION

VWAP mean reversion

Fade stretched moves back toward the volume-weighted average price in range-bound sessions. Works best with a regime filter that turns it off on trend days.

HYBRID

Partial automation

Human picks the level or setup; the machine handles entry execution, stop placement, sizing, and exits. In practice this human-in-the-loop model is what most serious retail algo traders run.

ML

AI trade filter

Keep your rule-based strategy, but add a machine-learning model that scores each setup's probability and skips low-quality signals. Enhances an edge instead of inventing one.

SEARCH

AI Generate (built into NinjaTrader)

NinjaTrader's experimental AI Generate optimizer uses a genetic algorithm across 70+ indicators and candlestick patterns to search for entry/exit combinations, with Monte Carlo checks against overfitting.

Section 04

AI agents: planning trades around events & conditions

A trading agent is more than a bot. A bot follows fixed rules ("RSI < 30 → buy"). An agent has three layers and can reason about context — the Fed statement released five minutes ago, not just the indicator on the chart.

LAYER 1

Research & reasoning (LLM)

A large language model (Claude, GPT, or an open-source model) ingests the economic calendar, news, earnings, Fed statements, and sentiment, and produces a market thesis and event plan.

LAYER 2

Decision framework

Hard-coded rules translate the thesis into signals with guardrails: max position size, daily loss limit, "flat before CPI," allowed instruments, allowed hours. The LLM proposes; the rules dispose.

LAYER 3

Execution

Broker/platform APIs place, modify, and close orders — a NinjaScript strategy, NinjaTrader's ATI interface, or a broker API for options (e.g., Alpaca, Tradier, Interactive Brokers).

An event-driven agent workflow (options on futures example)

DAILY LOOP (agent runs pre-market, e.g. 07:30 ET)
1. FETCH   economic calendar → next 5 days (CPI, FOMC, NFP, earnings)
2. ASSESS  regime: trend vs range, realized vs implied volatility, VIX level
3. PLAN    per event:
           - "CPI Thursday 08:30: go flat futures by 08:15;
              defined-risk options only (long straddle or skip)"
           - "Quiet Tuesday, range regime: enable VWAP reversion on MES,
              max 2 contracts, daily loss limit $150"
4. PROPOSE orders → human approves (or auto within strict limits)
5. EXECUTE via platform API; log every decision + reasoning
6. REVIEW  end of day: agent writes a journal entry; human reads it

Why events matter for options

Scheduled events (FOMC, CPI, jobs reports, mega-cap earnings) are when implied volatility and gap risk spike. Agents are good at the bookkeeping humans skip: knowing every event, its historical average move, and whether current option prices over- or under-price it — then choosing defined-risk structures instead of naked exposure.

Open-source agent frameworks

Projects like TradingAgents, FinRL, FinRobot, and ai-hedge-fund show multi-agent designs — analyst agents, a risk agent, a trader agent debating each decision. They're research and decision-support tools, not profit machines; their real value is learning and paper-trading workflows.

Section 05

What's actually working: examples & lessons from 2025–2026

Real reported outcomes are mixed — that's the honest headline. The wins share a pattern: automation used for discipline and coverage, not for magic predictions.

Discipline enforcement beats prediction

Bloomberg-reported retail agent deployments in 2026 found results "mixed but directionally significant" — one trader's agent refused to chase Nvidia momentum after earnings, avoiding a large weekly loss. The win wasn't a clever forecast; it was the machine enforcing a rule the human would have broken.

Agents as trade journals: the highest-ROI use for beginners

AI journal agents (e.g., TradeZella's Zella AI) analyze your own trade history and surface patterns like "your win rate drops from 58% to 34% in the first 30 minutes of the session." For discretionary traders this analysis layer often improves results more than any execution bot, because the bottleneck is self-knowledge, not speed.

Multi-agent research systems on prediction markets

On event/prediction markets, autonomous agents (e.g., Olas's Polystrat on Polymarket) executed thousands of trades in a month with some standout individual returns — while data shows most human traders on those venues lose. The takeaway for futures/options traders: 24/7 coverage plus emotionless rule-following is a real structural edge; headline return numbers are cherry-picked.

The cautionary side

The same 2026 reporting is full of losses: DCA bots buying "oversold" dips blind to a hawkish Fed transcript released minutes earlier, marketplace strategies overfit to a two-week window, and traders who overrode their own agents on gut feel. Vendor-published agent returns (100%+ annualized claims) are marketing until verified on your own paper account.

Section 06

Best practices — the non-negotiables

1 · Simulate first, always

Weeks in SIM, then micros with one contract. No strategy touches real money on backtest results alone.

2 · Risk ≤ 1–2% per trade

Position size from your stop distance, not from what margin allows. Hard daily loss limit; the platform enforces it, not willpower.

3 · Guard against overfitting

Out-of-sample and walk-forward testing are mandatory. A strategy tuned to look perfect on history usually fails live. Fewer rules, more robustness.

4 · Model costs & slippage

Commissions and slippage are first-class variables in expected value — backtests without them are fiction, especially for scalping.

5 · LLM proposes, rules dispose

Never let a language model place unconstrained orders. Wrap it in hard limits: instruments, size, hours, loss caps, and (early on) human approval.

6 · Plan around events

Know every FOMC/CPI/NFP release. Default: flat or defined-risk options through binary events. Undefined risk into a Fed decision is gambling.

7 · Production infrastructure

Automated strategies need state management, reconnect logic, and uptime — many run on a VPS near the exchange. A crashed PC with an open position is a real risk mode.

8 · Log everything, review weekly

Every decision, every fill, every agent rationale gets logged. If win rate degrades below your tested band, pause and investigate — don't tweak live.

Stock index futures — details

Index futures are standardized contracts on CME Group exchanges. Key specs to know: tick size (smallest price move), tick value ($ per tick), contract months (quarterly: Mar/Jun/Sep/Dec, e.g., "ES 09-26"), and margin (intraday vs overnight). Futures trade nearly 23h/day Sunday evening through Friday, with a daily maintenance break.

Micro E-mini contracts

Launched by CME in 2019, micros are 1/10th of E-minis: MES ≈ $5/point ($1.25/tick), MNQ ≈ $2/point ($0.50/tick). Typical intraday margins at futures brokers run roughly $40–$200 per micro contract (varies by broker and volatility). A beginner risking $20–$40 per trade on one MES contract can survive the learning curve that would destroy an account trading full-size ES.

Options on futures — the event tool

Buying a call/put on ES defines your worst case: the premium. Around binary events, common defined-risk structures include long straddles/strangles (betting on a big move either way), vertical spreads (directional with capped risk), and iron condors (betting the move stays inside a range — riskier around events). CME also lists Micro E-mini options for smaller accounts. Selling naked options into events is where accounts die; beginners should stick to long or spread structures.

Risk rules of thumb

  • Risk 1% (max 2%) of the account per trade; size positions from stop distance.
  • Set a hard daily loss limit (2–3R). When hit, the platform locks you out — not tomorrow-you.
  • Never average down a losing futures position.
  • Be flat, or defined-risk-only, through FOMC/CPI/NFP if you're a beginner.
  • Expect losing streaks: a 50%-win-rate system will hit 6+ losses in a row regularly. Size so that's survivable and boring.

Opening Range Breakout

Logic: record the high/low of the first 15–30 minutes after the 9:30 ET equity open. Buy a break above the high (sell a break below the low) with a volume filter, stop at the opposite side or mid-range, target 1–2× the range. Common failure: choppy days generate whipsaw double-breaks — many implementations allow only one trade per direction per day and skip days with unusually small ranges. Fully expressible in Strategy Builder with time filters.

EMA crossover trend following

Logic: fast EMA crossing above slow EMA = long bias; crossing below = short/exit. Works because index futures spend meaningful time in institutional-flow-driven trends — and bleeds money in ranges, so pair it with a regime filter (e.g., ADX > 20, or price distance from VWAP) and a trailing stop. It's the ideal first Strategy Builder + Strategy Analyzer project: simple enough to understand every trade in the backtest.

VWAP mean reversion

Logic: when price stretches 1.5–2 standard-deviation bands away from VWAP without new information, fade back toward VWAP with a tight stop. Its edge is regime-dependent — profitable in balanced/range sessions, dangerous on trend days (you're fading a freight train). This is exactly where an AI condition layer helps: classify today's regime pre-market (event calendar, overnight range, gap size) and only arm the strategy on range-probable days.

Partial automation (human-in-the-loop)

Some judgments — "is this retest holding?", "does this pullback look healthy?" — are genuinely hard to codify. The pragmatic 2026 pattern: the trader identifies the level or setup; automation then handles what machines do better — instant entry execution, exact stop/target placement via ATM templates, position sizing math, trailing logic, and the daily loss lockout. You keep the judgment, delete the execution errors and the emotion.

ML trade filter — the practical AI pattern

Workflow: (1) collect historical bars + indicator values + your strategy's signals; (2) train a classifier (gradient boosting or a small neural net) to predict whether each signal would have hit target before stop; (3) export the model (ONNX, or .NET-native via Accord.NET/ML.NET); (4) load it inside a NinjaScript strategy; (5) only take signals scored above a probability threshold. This enhances a working edge rather than trying to conjure one — the approach with the best track record for retail ML.

Libraries: Accord.NET · ML.NET · ONNX Runtime

AI Generate (Strategy Analyzer)

NinjaTrader's built-in experimental optimizer combines up to 73 default indicators, 25 candlestick patterns, and single-series custom indicators, using a genetic algorithm to search entry/exit combinations. To guard against curve-fitting it validates each generation with a Monte Carlo simulation at a 95% confidence interval. Treat its output as idea generation — you still walk-forward test and sim-trade anything it finds before believing it.

Event playbook

  • FOMC (8×/year, 14:00 ET): flat futures into the statement; expect violent two-way moves through the press conference. Defined-risk options or nothing.
  • CPI / PPI (monthly, 08:30 ET): pre-market release gaps index futures instantly. Same rule.
  • Nonfarm Payrolls (first Friday, 08:30 ET): similar profile to CPI.
  • Mega-cap earnings weeks: NQ/MNQ volatility clusters around NVDA/AAPL/MSFT reports after the close.

An agent's job: pull the calendar weekly, compute the instrument's average historical move per event type, compare to what the options market is pricing, and pre-write the plan (flat / straddle / reduce size) so the decision is made before adrenaline exists.
